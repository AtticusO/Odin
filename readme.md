# Odin
A self hosted replacement for Alexa

## Running Odin on the Raspberry Pi
```
python3 Odin0.py
```
## Install
```
pip install -r requirements.txt
```
### Dependancies
 ollama
<br> langchain-ollama
<br> langchain
<br> openai-whisper
<br> numpy
<br> spotipy
<br> sounddevice
<br> datetime
